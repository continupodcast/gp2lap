GP2 / HUD Editor

Bundled configuration loaded. Changes take effect after restarting GP2.

In-game controls

Choose target cars in the Drivers tab using the Drain column. After exporting and restarting GP2, press 7 during live driving to empty their fuel tanks. Fuel is held at zero for the selected duration in simulation time. The operation does not restore fuel afterward.

Original game announcements

Checked means hidden. Restart GP2 after exporting. The original Fastest Lap text is always hidden; GP2Lap graphics remain available. Other session announcements are preserved.

Preview

Approximate preview. GP2 maps colours to its 256-colour palette. Tower logos are 16 × 12 pixels; the driver card uses a smaller version.

How to use

  1. Edit teams and drivers.
  2. Import logos and adjust their visibility.
  3. Export and extract the ZIP into the game folder, beside the new GP2LAP.EXE.
  4. Restart GP2Lap/GP2.

Save project preserves logos for future editing. To open a CFG with external logos, also select its .F1L files. All processing takes place locally in this browser.
